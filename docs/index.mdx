# Introduction

`chapa-nodejs` is a TypeScript-first SDK for integrating [Chapa](https://chapa.co) payments into your Node.js application. It wraps the Chapa API into a single `Chapa` class with async methods for every core workflow — from creating a checkout session to verifying a completed payment and registering split-payment subaccounts.

The SDK ships with complete type definitions for every request and response, a built-in utility for generating unique transaction references, and validation helpers so malformed payloads fail early on the client rather than deep inside an API call.

If you're just getting started, head to [Installation](/docs/installation) to add the package to your project, then follow the [Quickstart](/docs/quickstart) to make your first API call. For more targeted workflows — like verifying payments after redirect or setting up split payments — see the [Guides](/docs/guides).

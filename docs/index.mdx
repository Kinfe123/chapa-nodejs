# chapa-nodejs

`chapa-nodejs` is a fully-typed Node.js SDK for the [Chapa](https://chapa.co) payment gateway. It gives you a clean, promise-based API to initialize transactions, verify payments, split revenue across subaccounts, and look up supported banks — all with first-class TypeScript support out of the box.

The SDK wraps every Chapa endpoint you need for a complete payment flow: you start a transaction and receive a hosted checkout URL, redirect your customer, then verify the result server-side using the transaction reference. Split payments let you route portions of a charge to registered subaccounts in either percentage or flat-fee mode.

If you're new here, head to [Installation](/docs/installation) to add the package to your project, then follow the [Quickstart](/docs/quickstart) to make your first API call in under five minutes. The [Guides](/docs/guides) cover common workflows and troubleshooting once you're past the basics.

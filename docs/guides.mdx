# Guides

These guides cover the practical workflows you'll reach for after the initial setup. Each one focuses on a single task and gives you copy-pasteable code you can drop straight into your project.

- **Split Payments** — collect a transaction and automatically distribute a share to one or more subaccounts at settlement time.
- **Subaccounts** — register a merchant bank account with Chapa so it can receive split revenue.
- **Troubleshooting** — recover from the most common errors around credentials, validation, and API responses.

If you haven't set up the SDK yet, start with [Installation](/docs/installation). Once you're configured, the [Quickstart](/docs/quickstart) shows the end-to-end payment flow before you add splits or subaccounts.
